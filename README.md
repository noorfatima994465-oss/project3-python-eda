# Project 3 — Python & Pandas EDA
## Overview
This project focuses on Exploratory Data Analysis (EDA) of student performance data using Python and Pandas.
The goal is to clean, explore, analyze, and visualize the dataset to identify meaningful patterns related to student performance.
## Tools Used
 Python
 Pandas
 NumPy
 Matplotlib
 Google Colab
## Dataset
The dataset is a student performance dataset created for this project. It contains information about 50 students, including their age, gender, city, study hours, attendance, assignment scores, exam scores, and final marks.
The dataset also contains a few missing values to practice data cleaning and missing-value handling.
## Analysis
The project includes:
 Loading and understanding the dataset
 Checking rows, columns, and data types
 Data cleaning
 Missing-value handling
 Descriptive statistics using `describe()`
 Sorting and filtering data
 Groupby analysis
 Average final marks by gender and city
 Correlation analysis
 Data visualization using Matplotlib
 Study hours vs. final marks analysis
## Key Insights
1. Students' final marks can be compared based on their study hours, attendance, assignments, and exam scores.
2. The average final marks vary between different gender groups.
3. The average final marks also differ across cities.
4. Study hours and final marks can be analyzed using a scatter plot and correlation to understand their relationship.
## Conclusion
This project provided practical experience in using Python and Pandas for Exploratory Data Analysis.
I learned how to load and understand a dataset, identify and handle missing values, perform statistical and groupby analysis, visualize data, and extract meaningful insights from raw data.
